# PrintLab para Windows

Programa para imprimir boletos de rifa numerados, talonarios de factura, impresiones a 2 lados, pósteres en varias hojas y certificados masivos desde Excel.

## Descargar

**[Descargar Impresion-Setup.exe (última versión)](https://github.com/developerdv1studio-web/impresion-app/releases/latest/download/Impresion-Setup.exe)**

También puedes ver todas las versiones en [Releases](https://github.com/developerdv1studio-web/impresion-app/releases).

Requisitos: Windows 10 u 11. Si Windows muestra «Windows protegió su PC», pulsa **Más información → Ejecutar de todas formas**.

El programa avisa solo cuando hay una versión nueva.
